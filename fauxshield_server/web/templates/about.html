Anti-counterfeit infrastructure, rebuilt on Serverpod.

FauxShield started as a question with an uncomfortable answer: a printed QR code proves nothing on its own. Anyone can photograph a code and print it again. The code is not the defence — the identity behind it is.

Why it exists

Counterfeiting is not a packaging problem.

Counterfeit medicine, seeds, pesticides, and electronics destroy trust and sometimes lives. The brands that suffer most are often the ones with the least infrastructure to fight back: no unit level record, no way to prove a product came from them, and no mechanism to warn buyers when something goes wrong. FauxShield is an attempt to make that infrastructure ordinary rather than enterprise only.

How it is built

One repository, one full stack.

The server, the API, the database schema, the background jobs, the web pages, and the operator app all live together and are generated from the same model definitions.

What Serverpod does here

The platform is not a wrapper around it.

Serverpod is not used as a thin transport. The identity system, the fraud engine, and the operations surface are all expressed in its primitives.

Context

Built for the Build Something Real hackathon.

This implementation was produced for Build Something Real: The Serverpod Hackathon. The domain model came from an earlier prototype of the same product idea, which was used as reference material and is not part of this repository. The server, the Flutter app, the web pages, the migrations, and the tests in this repository were written against the Serverpod SDK, with an AI coding agent as the primary development tool under human direction: every change was reviewed and verified locally by running the analysis, the test suite, and the running application in a browser.

If you are reading this to evaluate the project, the fastest path is to start the server, sign in, and open the demo workspace. Everything described on these pages is reachable from there.

Judge it by using it.

The demo workspace comes preloaded, and the consumer flow works from a link with no account at all.
