The solution

One platform, from product identity to verified authenticity.

FauxShield fits an existing production line. Standard QR codes on the packaging you already print, backed by cryptographic identities, a fraud engine, and a response workflow — with no special hardware for the consumer and no SMS bill.

How it works

From a printed label to a defensible answer.

Five steps, all of them running inside one Serverpod server.

1

Serialize the batch

Create a product, then a batch. Each unit is minted with its own QR token, HMAC signature, hashed PIN, and encrypted PIN copy for audited reveals.

2

Print and ship

Export the batch as CSV or TSV and send the codes to your existing print process. No new hardware and no proprietary tags.

3

Consumer scans the label

The code opens a web page that works without an app. The server resolves the token, records where it came from, and asks for the PIN under the scratch panel.

4

The engine scores the scan

Eight signals are evaluated against the workspace policy inside a time budget. Suspicious scans escalate to an alert with the evidence attached.

5

Investigate and respond

Triage alerts, assign owners, reveal or regenerate a compromised token, and recall a batch — with every action written to the audit log.

Field operations

Inspections that keep working without a network.

Warehouses, ports, and rural distributors are exactly where the signal is worst. The inspector app keeps scanning, queues the work locally, and reconciles when connectivity returns.

  • Scans are stored on the device with a local id and device id
  • A provisional verdict is shown immediately, on device
  • Queued scans sync through Serverpod's database sync layer
  • The converter turns each synced scan into a real session
  • Authoritative outcomes are pushed back to the inspector
  • Consumer reports queued offline are delivered too
