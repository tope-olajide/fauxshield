Options

Three ways to run the same platform.

This page describes deployment, not a hosted price list. This build contains no billing or payment integration.

{{{iconCode}}}

Self-hosted

Free

Clone the repository and run it. Everything in this build is included, under the MIT licence.

  • Serverpod server, Flutter app, and migrations
  • All eight fraud signals and the simulation suite
  • Roles, API keys, audit log, and analytics
  • Embedded PostgreSQL for development, no Docker
  • You operate the database and the secrets
{{{iconActivity}}}

Serverpod Cloud

Usage-based

One command builds, deploys, and wires up the infrastructure for you.

  • serverpod cloud launch from the server folder
  • Managed PostgreSQL with migrations applied on boot
  • Managed secrets through the CLI, kept out of the repo
  • API, Insights, and web URLs provisioned for you
  • Built-in cloud storage for branding assets
{{{iconShield}}}

Enterprise

Talk to us

For deployments with specific integration, data residency, or review requirements.

  • Deployment review against your environment
  • Integration support for existing print and ERP pipelines
  • Key management and rotation planning
  • Migration and upgrade assistance
  • A named contact instead of a support queue
Included everywhere

No tier withholds a module.

Because FauxShield ships as one server, every deployment gets the same surface. What differs is who carries the operational load.
